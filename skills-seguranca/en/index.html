THE ALERT

Two public reports. Neither says every skill is malware.

The numbers come from the sources, with links. They ask for a review. They are not a certificate against the skill you already use, or for it.

31,132

skills analyzed

The study Agent Skills in the Wild, by Yi Liu and colleagues, January 2026. Skills taken from marketplaces.

26.1%

worth a review

At least one pattern worth reviewing. The paper itself asks you to read that number this way, not as confirmed malware.

5.2%

high severity

Patterns that suggest malicious intent, such as obfuscated code, a hidden instruction, credential collection, or a fetch of an external script.

341

malicious skills

Koi Security found 341 malicious skills on ClawHub, the OpenClaw store. The article describes theft of passwords, SSH keys, and API keys.

Sources: arXiv, Agent Skills in the Wild · The Hacker News, on Koi Security

Yi Liu and colleagues wrote the study. Koi Security did the audit cited by The Hacker News. They did not write this collection. A scanner that finds nothing is not a certificate either.

HOW TO INSTALL

ZIP, README, skill folder.

The path for each agent is in the README. This is the short version. Do not run a script from the ZIP until you have read the file.

01

Download the ZIP

Use the download button on this page, or Code, then Download ZIP, on GitHub. Unzip it.

02

Read the README

README-en.md says what each folder does, the license, and what not to copy on day one.

03

Copy the skill folder

A skill is the folder that contains SKILL.md. Copy that folder into your agent: Grok, Claude, Gemini, Codex, or Cursor.

Do not copy the whole avancado folder on day one. Do not copy tests or evals from the scanners. The folder path for each agent is in the English README. The Portuguese text is README.md.

WHAT TO DO TODAY

Four steps before you install any skill.

The skill review-skill-before-installing walks these steps with you. A clean result is not a certificate. The decision stays with you.

  1. Known source.
  2. Read the SKILL.md and the scripts.
  3. Run it through a scanner (SkillSpector or the Cisco skill-scanner, if one is already installed).
  4. A command from a strange site in the terminal: delete the skill folder and do not run the command.

The verdict the skill returns is safe to install, review carefully, or do not install.
