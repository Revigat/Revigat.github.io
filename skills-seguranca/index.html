O ALERTA

Dois relatos públicos. Nenhum diz que toda skill é malware.

Os números vêm das fontes, com link. Eles pedem revisão. Não são um atestado contra a skill que você já usa, nem a favor dela.

31.132

skills analisadas

Estudo Agent Skills in the Wild, de Yi Liu e colegas, janeiro de 2026. Skills tiradas de marketplaces.

26,1%

merecem revisão

Ao menos um padrão que merece revisão. O próprio artigo pede para ler esse número assim, não como malware confirmado.

5,2%

alta gravidade

Padrões que sugerem intenção maliciosa, como código ofuscado, instrução escondida, coleta de credencial ou busca de script externo.

341

skills maliciosas

A Koi Security achou 341 skills maliciosas no ClawHub, a loja do OpenClaw. A matéria descreve roubo de senhas, chaves SSH e chaves de API.

Fontes: arXiv, Agent Skills in the Wild · The Hacker News, sobre a Koi Security

Yi Liu e colegas escreveram o estudo. A Koi Security fez a auditoria citada pela The Hacker News. Eles não escreveram esta coleção. Um scanner que não acha nada também não é um atestado.

COMO INSTALAR

ZIP, LEIAME, pasta da skill.

O caminho de cada agente está no LEIAME. Aqui vai o caminho curto. Não rode um script do ZIP antes de ler o arquivo.

01

Baixe o ZIP

Use o botão de download desta página, ou Code e Download ZIP no GitHub. Descompacte.

02

Leia o LEIAME

O arquivo README.md diz o que cada pasta faz, a licença e o que não copiar no primeiro dia.

03

Copie a pasta da skill

Uma skill é a pasta que contém SKILL.md. Copie essa pasta para o seu agente: Grok, Claude, Gemini, Codex ou Cursor.

Não copie a pasta avancado inteira no primeiro dia. Não copie tests nem evals dos scanners. O detalhe de pasta de cada agente está no LEIAME (README.md). A versão em inglês do mesmo texto é o README-en.md.

O QUE FAZER HOJE

Quatro passos antes de instalar qualquer skill.

A skill revisar-skill-antes-de-instalar faz esses passos com você. Um resultado limpo não é um atestado. A decisão continua com você.

  1. Fonte conhecida.
  2. Ler o SKILL.md e os scripts.
  3. Passar no scanner (SkillSpector ou o skill-scanner da Cisco, se já estiver instalado).
  4. Comando de site estranho no terminal: apague a pasta da skill e não rode o comando.

O veredito que a skill devolve é seguro para instalar, revisar com cuidado ou nao instalar.
